# Scripps-Summer2024
This repository has the work I completed during Summer 2024 at UC San Diego, Scripps Institution of Oceanography.

During the summer of 2024, I worked at UC San Diego, Scripps Institution of Oceanography as a Software Engineering Research Intern. I worked with a PhD student interested in the efficiency of biogeochemical floats in the ocean--instruments that collect relevant scientific data at varying depths to better understand how the ocean works and how to counter the effects of global warming. I developed Python code that performs a randomized experiment to assess the functionality of these floats by creating hypothetical float arrays at different locations in each major ocean. The goal was to minimize the cost and maximize the efficiency of these float arrays, using a data set of ~200,000 entries to model the ocean’s behavior. The result of my work was that we discovered which sensors and regions should be prioritized for future float deployments, saving the program upwards of an estimated $300,000 annually. 

Frameworks and Python modules used: OS, Matplotlib, Pickle, Numpy, SciPy.

The regions that I analyzed were the Indian Ocean, Southern Ocean, North Atlantic, Tropical Atlantic, South Atlantic, North Pacific, California Current Stream, Tropical Pacific, South Pacific, and the Gulf of Mexico. I considered float at the following depths: 15m, 40m, 87.5m, 137.5m, 225m, 350m, 550m, 750m, 950m, 1150m, 1350m, 1625m, and 2250m. The experiment also accounted for different sizes of float arrays, ranging from 10 floats to 60 floats. I compared the effectiveness of floats containing oxygen sensors, pH sensors, and chlorophyll sensors, with each hypothetical float array containing a certain percentage of each one of these sensors ranging from 0-100%.

The graphs in this repository each represent a collection of individual experiments, all in one region, at one depth level, and equipped with one biogeochemical sensor. Unconstrained variance is a measure of how effective each point (one hypothetical float array) is, with lower unconstrained variance implying increased effectiveness. The x-axis represents the cost of the float arrays and the color bar on the right displays the percentage of floats in each array that contain the specified sensor. 

Therefore, plotting Pareto frontiers is an effective way of visualizing the data in order to minimize both the unconstrained variance and cost. We can conclude that a specific sensor should be used in a certain region if the Pareto frontier displays high percentages of that sensor (yellow in the graphs). With this methodology, from the example graphs shown in this repository, it is clear that oxygen sensors should be used in the Indian Ocean around depths of 15 meters and chlorophyll sensors should be used around depths of 87.5 meters, while pH sensors are less effective in the Southern Ocean around depths of 40 meters.

This project was a revolutionary experience for me, as I was able to develop object-oriented software to make a significant impact on a highly relevant, real-world application!
